Docker Compose + MySQL

Suba um banco MySQL com dados persistentes, acessível pelo terminal e pelo DBeaver.

1

Pré-requisitos

Você precisa ter instalado:

  • Docker — o motor que roda os containers
  • Docker Compose — orquestra containers via arquivo YAML (já vem no Docker Desktop)

Verifique:

terminal 
docker --version
docker compose version
2

Criar a pasta do projeto

terminal 
# Cria a pasta e entra nela
mkdir meu-mysql && cd meu-mysql
3

Criar o docker-compose.yml

Arquivo principal com cada linha comentada:

docker-compose.yml 
# Versão da sintaxe do Compose
version: "3.8"

services:
  mysql:
    # Imagem oficial do MySQL (versão 8)
    image: mysql:8

    # Nome fixo do container
    container_name: meu_mysql

    # Reinicia sozinho se o Docker reiniciar
    restart: unless-stopped

    # Variáveis de ambiente (configuram o banco)
    environment:
      # Senha do usuário root (obrigatória)
      MYSQL_ROOT_PASSWORD: root_senha_123

      # Cria um banco automaticamente ao iniciar
      MYSQL_DATABASE: meu_banco

      # (Opcional) Cria um usuário além do root
      MYSQL_USER: admin
      MYSQL_PASSWORD: admin_senha_123

    # Mapeia a porta do container para a máquina
    # 3306 é a porta padrão do MySQL
    ports:
      - "3306:3306"

    # VOLUME: onde os dados ficam salvos!
    # /var/lib/mysql é a pasta de dados do MySQL
    volumes:
      - mysqldata:/var/lib/mysql

# Declara o volume nomeado
# É isso que garante a persistência dos dados!
volumes:
  mysqldata:
Por que o volume? Sem o volume, os dados ficam dentro do container. Com docker compose down, o container é removido e os dados vão junto. O volume nomeado mysqldata guarda os dados num local separado gerenciado pelo Docker.

MySQL vs PostgreSQL

A pasta de dados muda: MySQL usa /var/lib/mysql, Postgres usa /var/lib/postgresql/data

Dois usuários

root é o superusuário. O MYSQL_USER cria um segundo usuário com acesso ao banco definido em MYSQL_DATABASE.

4

Subir o container

terminal 
# -d = roda em segundo plano (detached)
docker compose up -d

# Veja se está rodando
docker ps

Você verá o container meu_mysql com status Up. O MySQL pode levar uns 10-20 segundos para inicializar na primeira vez.

5

Acessar pelo Terminal

Duas formas de conectar:

Opção A — com o usuário admin 
# Executa o cliente mysql dentro do container
# -u = usuário | -p = vai pedir a senha
docker exec -it meu_mysql \
  mysql -u admin -p meu_banco

# Quando pedir a senha, digite: admin_senha_123
Opção B — com o usuário root 
# Root tem acesso total a todos os bancos
docker exec -it meu_mysql \
  mysql -u root -p

# Quando pedir a senha, digite: root_senha_123

Comandos úteis dentro do mysql:

ComandoO que faz
SHOW DATABASES;Lista todos os bancos
USE meu_banco;Seleciona um banco
SHOW TABLES;Lista tabelas do banco atual
DESCRIBE tabela;Mostra estrutura de uma tabela
exitSai do mysql
6

Acessar pelo DBeaver

Crie uma nova conexão MySQL com:

CampoValor (admin)Valor (root)
Hostlocalhostlocalhost
Porta33063306
Databasemeu_banco(deixe vazio)
Usuárioadminroot
Senhaadmin_senha_123root_senha_123

Clique em Test Connection para validar, depois Finish.

Porta ocupada? Se a 3306 já estiver em uso (outro MySQL instalado), mude no docker-compose.yml para "3307:3306" e use a porta 3307 no DBeaver.
Driver não encontrado? Na primeira conexão MySQL, o DBeaver pede para baixar o driver. Clique em Download e aguarde.
7

Testar a persistência

Vamos criar dados, derrubar o container e verificar que nada se perdeu:

terminal 
# 1. Conecta e cria uma tabela com dados
docker exec -it meu_mysql \
  mysql -u admin -padmin_senha_123 meu_banco -e "
    CREATE TABLE teste (
      id INT AUTO_INCREMENT PRIMARY KEY,
      nome VARCHAR(100)
    );
    INSERT INTO teste (nome) VALUES ('Docker funciona!');
  "

# 2. Derruba e REMOVE o container
docker compose down

# 3. Sobe novamente
docker compose up -d

# 4. Verifica se os dados continuam lá
docker exec -it meu_mysql \
  mysql -u admin -padmin_senha_123 meu_banco -e "SELECT * FROM teste;"

# Resultado esperado:
# +----+------------------+
# | id | nome             |
# +----+------------------+
# |  1 | Docker funciona! |
# +----+------------------+
Nota sobre o -p No MySQL, o -p colado na senha (sem espaço) evita que ele peça a senha interativamente. Com espaço (-p admin_senha_123) ele interpreta a senha como nome do banco.

Comandos do dia a dia

AçãoComando
Subirdocker compose up -d
Parar (mantém container)docker compose stop
Parar e remover containerdocker compose down
Ver logsdocker compose logs -f

Cuidado com o -v O docker compose down -v apaga os volumes. Isso deleta todos os seus dados permanentemente!
